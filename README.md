# 🚀 Run Portfolio Locally

Clone the repository:

```bash
git clone https://github.com/vinaypansare18/portfolio.git
```

Navigate to the project:

```bash
cd portfolio
```

Open:

```text
index.html
```

in your browser.

No backend server is required for the basic portfolio because it is a static website.

# 🌍 Deployment

The portfolio can be deployed using **GitHub Pages**.

Once GitHub Pages is enabled, the portfolio can be accessed through a public URL such as:

```text
https://vinaypansare18.github.io/portfolio/
```

> The exact URL depends on the repository name and GitHub Pages configuration.

---

# 🔄 Updating the Live Portfolio

The portfolio can be maintained through Git.

After making changes locally:

```bash
git add .
```

```bash
git commit -m "Update portfolio"
```

```bash
git push
```

If GitHub Pages is configured for the repository, the live website will automatically update after GitHub receives the latest changes.
